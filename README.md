# Deployment Savings Tracker V1

A minimal personal savings tracker for deployment. No prefilled personal information.

## Features
- Starting balance, savings goal, deployment dates
- Deposits and withdrawals with transaction history
- Progress, countdown and simple projected savings
- Local browser storage and JSON backup/restore

## GitHub Pages
Create a repository, upload `index.html` at its root, and enable Pages under Settings → Pages → Deploy from branch → main / root.

## Privacy
All data is stored in the current browser's localStorage. GitHub Pages hosting does not make your savings records public, but other people with access to your unlocked device/browser profile may see them. Export backups regularly. No cloud sync or background notifications.

## Forecast note
The forecast extrapolates net recorded transactions per elapsed deployment day. It may be unreliable early in the deployment or when records are incomplete. This is not financial advice.
